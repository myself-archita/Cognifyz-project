# Cognifyz Internship Task 4

This project demonstrates:

- complex client-side form validation
- password strength checking
- dynamic DOM updates based on user input
- client-side routing with a single-page style experience

## Run locally
```bash
npm install
npm start
```

Then open:
[http://localhost:3004](http://localhost:3004)

## Files
- `server.js` — Express server
- `views/index.ejs` — responsive single-page UI
