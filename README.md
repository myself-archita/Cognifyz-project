# Cognifyz Project

This repository groups all five Cognifyz internship tasks into one place.

## Task Folders

| Task | Folder | What’s inside |
| --- | --- | --- |
| 1 | [`task1/`](./task1) | Task 1 app and views for the first Cognifyz assignment. |
| 2 | [`task2/`](./task2) | Task 2 app and views for the second Cognifyz assignment. |
| 3 | [`task3/`](./task3) | Task 3 app and views for the third Cognifyz assignment. |
| 4 | [`task4/`](./task4) | Task 4 app and views for the fourth Cognifyz assignment. |
| 5 | [`task5/`](./task5) | Task 5 full-stack API dashboard with backend integration. |

## Quick Notes

- Each folder is self-contained and can be run independently.
- Install dependencies inside the task folder before starting that app.
- Task 5 connects to the backend API and PostgreSQL-powered data store.

## How to Run

Run each task from its own folder:

- `task1/`
  - `cd task1`
  - `npm install`
  - `npm start`
- `task2/`
  - `cd task2`
  - `npm install`
  - `npm start`
- `task3/`
  - `cd task3`
  - `npm install`
  - `npm start`
- `task4/`
  - `cd task4`
  - `npm install`
  - `npm start`
- `task5/`
  - `cd task5`
  - `npm install`
  - `npm start`
  - Make sure the backend API is running if you want live task data.
