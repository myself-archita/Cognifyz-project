# Cognifyz Internship Task 3

This project demonstrates:

- advanced CSS styling with layered effects and animations
- a complex multi-section layout
- a responsive UI built with Bootstrap

## Run locally
```bash
npm install
npm start
```

Then open:
[http://localhost:3003](http://localhost:3003)

## Files
- `server.js` — Express server
- `views/index.ejs` — responsive single-page layout
