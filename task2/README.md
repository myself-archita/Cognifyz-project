# Cognifyz Internship Task 2

This project demonstrates:

- inline styling and a polished multi-field form
- basic client-side validation using inline JavaScript
- server-side validation with Express
- temporary in-memory storage for validated submissions

## Run locally
```bash
npm install
npm start
```

Then open:
[http://localhost:3002](http://localhost:3002)

## Files
- `server.js` — Express routes, validation, and in-memory storage
- `views/index.ejs` — form UI and inline validation
- `views/result.ejs` — submission confirmation
- `views/submissions.ejs` — stored submissions view
