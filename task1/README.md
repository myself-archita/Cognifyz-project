# Cognifyz Task 1 — HTML Structure and Basic Server

This project is a simple internship-ready demonstration of server-side rendering and basic form submission using **Node.js**, **Express**, and **EJS**.

## What it does
- Displays a professional HTML form for user input
- Handles form submission on the server
- Validates required fields before rendering results
- Uses EJS to generate the response page dynamically

## How to run
1. Open a terminal in this folder
2. Install dependencies if needed:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open:
   [http://localhost:3001](http://localhost:3001)

## Project structure
- `server.js` — Express server and routes
- `views/index.ejs` — form page
- `views/result.ejs` — submission result page

## Tech stack
- Node.js
- Express.js
- EJS
- HTML/CSS
